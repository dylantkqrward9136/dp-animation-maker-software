## Overview

DP Animation Maker is a Windows desktop application for adding movement and visual effects to still images and layered source artwork. It brings scene assembly, animation effects, and preview tools together in a workflow intended for 2D projects.

Animators, designers, and content creators can combine image assets, PSD layers, audio timing, particles, and environmental effects within the same application. Projects can be adjusted interactively during development or rendered through an unattended process when repeatable output is needed.

---

## What It Provides

- Turns still images into animated scenes
- Delivers real-time preview with GPU acceleration
- Opens and uses layered PSD artwork
- Offers headless command-line rendering for batch jobs
- Analyzes audio waveforms and detects beats for timing work
- Supports particle effects for added movement and atmosphere
- Includes weather effects for scene styling
- Runs as a Windows desktop tool focused on 2D animation

## Typical Workflow

To create an animated scene:

1. Start DP Animation Maker.
2. Load a still image or a layered PSD.
3. Apply motion and, where appropriate, particle or weather effects.
4. Inspect the result using the GPU-assisted preview.
5. Add audio-based timing for movement or transitions when required.
6. Export the scene directly, or send it through batch rendering for repeated jobs.

Builds that include the headless workflow can use command-line rendering for scripted exports, render queues, and other unattended tasks.
